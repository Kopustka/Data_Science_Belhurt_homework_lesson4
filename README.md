# Data_Science_Belhurt_homework_lesson4
This is homework for the courses Data Science. Done using libraries: pandas, matplotlib, seaborn. I analyzed the database: "Titanic Dataset".
This is homework from the courses Belhurt course.

Usage:
Running the main.py file to start the project. 
The modules in the project are: 

loader.py
Loads data for use. JSON and CSV data can be loaded.

visualization.py
Module allowing to visualize data from the table, the visualization parameters can be changed in main.py.

missing_values.py
This module searches and analyzes missing values in the database. It counts the number of missing values in each column, makes a table of the percentage of missing values to the total number of values and so on.

fillter.py 
This module is needed to fill missing values with the mean or median value.(this can be customized in main.py).
It will create a separate file with the modified database.

In the data directory you need to load the database you need for interactions and specify its name in main.py.
